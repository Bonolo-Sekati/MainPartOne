- QuickChat – Java Chat Application

-Description
QuickChat is a Java console-based chat application developed in NetBeans. It includes user registration and login functionality, message validation, and options to send, disregard, or store messages for later.

* Features
- User registration and login.
- Username and password validation.
- South African cellphone number validation.
- Send messages of up to 250 characters.
- Generate unique message IDs and message hashes.
- Display message details and track the total number of messages sent.
- Store and retrieve messages using JSON files.

*Technologies Used
- Java
- NetBeans IDE
- Maven
- JSON (`org.json`)

* How to Run
1. Clone or download this repository.
2. Open the project in NetBeans.
3. Ensure the required dependencies are configured in `pom.xml`.
4. Build and run `MainPartOne.java`.
5. Follow the on-screen instructions to register, log in, and use QuickChat.
